# Code of Conduct

We pledge to make participation in this project a harassment-free experience for everyone,
regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and
expression, experience level, education, socio-economic status, nationality, personal appearance,
race, religion, or sexual identity and orientation.

Be respectful, give actionable technical feedback, accept responsibility for mistakes, and focus on
what is best for the community. Harassment, threats, discriminatory language, sexualized attention,
doxxing, and sustained disruption are unacceptable.

Report conduct concerns privately through the repository owner's GitHub profile. Maintainers may
edit or remove contributions and temporarily or permanently ban participants whose behavior is
inappropriate. Enforcement decisions will be explained to affected parties where appropriate.

This policy is adapted from Contributor Covenant 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct.html
